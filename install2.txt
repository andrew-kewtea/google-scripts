# 1) 루트 의존성 동기화
pnpm install
# 2) 공통 TypeScript (권장)
pnpm add -Dw typescript
# (선택) 팀 재현성 위해 clasp도 로컬화할 때만

루트에서 하는 이유:

workspace 전체 의존성/버전 통일
lockfile 일원화
공통 도구(typescript) 중앙 관리


2) 개별 패키지 루트에서 할 일 (GAS 예시)
경로: /home/jungh/webProjects/google-scripts/apps/gas/bound/sheet_naim_connect

# 1) 패키지 초기화
pnpm init
# 2) 패키지 전용 dev deps
pnpm add -D @types/google-apps-script
# 3) clasp 인증 (1회)
clasp login
# 4) script clone (최초 1회)
clasp clone 1hSOCHFTgJwGHhXSqbJ3S5PriogI-a-8TdVXjfiXASRPjCjzxk3SVW8Hr


3) 패키지마다 반복할 템플릿

cd <패키지_폴더>
pnpm init
# GAS면
  (1) pnpm add -D @types/google-apps-script  # GAS 코드에서 자동완성/타입체크
# Chrome extension이면
   (2) # pnpm add -D @types/chrome
pnpm exec tsc --init

생성된 tsconfig.json을 GAS용으로 수정 (최소형)
{
  "compilerOptions": {
    "target": "ES5",
    "module": "none",
    "types": ["google-apps-script"],
    "strict": true,
    "noEmitOnError": true
  },
  "include": ["src/**/*.ts"]
}
